# 出力フォーマット

Harunobu は採点結果を **JSON** と **CSV** の2形式で出力します。

- **JSON出力**: システム連携やAIエージェント向け。ファイル、シート、テーブル、ルール結果を階層構造で保持します。
- **CSV出力**: 人間の確認や表計算ソフトでの一覧確認向け。1行が「1ファイル x 1シート x 1テーブル x 1ルール」の結果です。

`sample_app/harunobu/resources/analysis-output.schema.json` は、現行JSON出力を説明する参考スキーマです。バージョン管理された互換性契約ではありません。

## JSON 出力

### 出力例

```json
{
  "inputファイル名": "data.xlsx",
  "ファイルサイズ": 102400,
  "フォーマット": "xlsx",
  "Sheet数": 1,
  "レベル別スコア": {
    "1": {
      "スコア": 80,
      "合格": 4,
      "合計": 5,
      "強制0点": false,
      "強制0点ルール": [],
      "失敗ルール": [
        {
          "ルールID": "L1-12",
          "重大度": "critical"
        }
      ]
    },
    "2": null,
    "3": null
  },
  "sheets": [
    {
      "シート名": "Sheet1",
      "使用範囲": "A1:E10",
      "非表示": false,
      "評価対象エリア": [
        {
          "範囲": "A1:E10",
          "信頼度": 0.95,
          "ヘッダー行": [1],
          "ヘッダー範囲": "A1:E1",
          "列数": 5,
          "評価内容": [
            {
              "ルールID": "L1-12",
              "合否": false,
              "判定対象外": false,
              "重大度": "critical",
              "信頼度": 0.95,
              "違反": [
                {
                  "シート": "Sheet1",
                  "セル範囲": "A1:D1",
                  "説明": "結合セルが検出されました",
                  "違反重大度": "error"
                }
              ],
              "メッセージ": "1件のセル結合が検出されました"
            }
          ]
        }
      ]
    }
  ]
}
```

### トップレベル

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `inputファイル名` | string | 入力ファイル名 |
| `ファイルサイズ` | integer | ファイルサイズ（バイト） |
| `フォーマット` | string | `xlsx` / `csv` / `tsv` |
| `Sheet数` | integer | ファイル内のシート数 |
| `レベル別スコア` | object | Level 1〜3それぞれの採点結果。未評価レベルは `null` |
| `sheets` | array | シート別結果 |

Harunobu のJSON出力に総合評価点はありません。スコアは `レベル別スコア` でレベルごとに確認します。

### レベル別スコア

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `スコア` | integer | レベル別スコア（0〜100） |
| `合格` | integer | 合格したルール数 |
| `合計` | integer | 採点対象ルール数 |
| `強制0点` | boolean | fatal等の重大違反により0点扱いになったか |
| `強制0点ルール` | array | 強制0点の原因になったルール |
| `失敗ルール` | array | 不合格だったルール |

### シート

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `シート名` | string | シート名 |
| `使用範囲` | string | シートの使用範囲（例: `A1:E10`） |
| `非表示` | boolean | 非表示シートかどうか |
| `評価対象エリア` | array | 検出されたテーブルごとの結果 |
| `sheetProperty` | object | シートサイズ等の補足情報。存在する場合のみ出力 |
| `others` | array | テーブル外セル。存在する場合のみ出力 |

#### sheetProperty の内部フィールド

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `sheetName` | string | シート名 |
| `maxRow` | integer | シートの最終行番号 |
| `maxCol` | integer | シートの最終列番号 |
| `hidden` | boolean | 非表示シートかどうか |

#### others の内部フィールド（要素ごと）

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `row` | integer | 行番号 |
| `col` | integer | 列番号 |
| `value` | any | セルの値 |
| `regionType` | string | IslandDetector が付与したセル種別ラベル |

### 評価対象エリア

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `範囲` | string | テーブルのセル範囲 |
| `信頼度` | number | レイアウト検出の信頼度（0.0〜1.0） |
| `ヘッダー行` | array[integer] | ヘッダーと推定された行番号 |
| `ヘッダー範囲` | string/null | ヘッダーが占めるセル範囲。未検出なら `null` |
| `列数` | integer | テーブルの列数 |
| `評価内容` | array | ルール別チェック結果 |
| `columnHeaders` | array | 列ヘッダー情報。存在する場合のみ出力 |
| `columns` | array | 列スキーマ情報。存在する場合のみ出力 |

### ルール別チェック結果

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `ルールID` | string | ルールID（例: `L1-12`） |
| `合否` | boolean | チェックに合格したか |
| `判定対象外` | boolean | `confidence=0` により採点対象外として扱われたか |
| `重大度` | string | ルール失敗時の重大度。`fatal` / `critical` / `major` / `minor` / `info` |
| `信頼度` | number | チェック判定の信頼度（0.0〜1.0） |
| `違反` | array | 違反箇所の一覧 |
| `違反グループ` | object | 違反件数が20件を超えた場合の集計サマリ。存在する場合のみ出力 |
| `メッセージ` | string | 補足メッセージ |

### 違反

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `シート` | string | 違反が検出されたシート名 |
| `セル範囲` | string | 違反が検出されたセル範囲 |
| `説明` | string | 違反内容 |
| `違反重大度` | string | セル単位の重大度。`error` / `warning` / `info` |

### 違反グループ（違反件数が多い場合のみ）

違反件数が20件（`VIOLATIONS_DISPLAY_LIMIT`）を超えた場合、`違反グループ` フィールドが追加されます。`違反` フィールドには引き続き全件が保持されます。

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `合計件数` | integer | 違反の総件数 |
| `グループ` | array | (シート × 重大度) でまとめた集計リスト |

**グループ要素の内部フィールド:**

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `シート` | string | シート名 |
| `重大度` | string | 違反重大度（`error` / `warning` / `info`） |
| `件数` | integer | そのグループの違反件数 |
| `代表セル範囲` | array[string] | 代表として最大3件のセル範囲 |

## CSV 出力

CSV は次の15列を出力します。

| # | カラム名 | 説明 |
|---|---------|------|
| 1 | `ファイル名` | 入力ファイル名 |
| 2 | `シート名` | シート名 |
| 3 | `テーブル範囲` | テーブルのセル範囲 |
| 4 | `ヘッダー範囲` | ヘッダーが占めるセル範囲。未検出なら空文字 |
| 5 | `列数` | テーブルの列数 |
| 6 | `ルールID` | ルールID |
| 7 | `合否` | `合格` または `不合格` |
| 8 | `判定対象外` | 判定対象外の場合は `○` |
| 9 | `重大度` | ルール失敗時の重大度 |
| 10 | `信頼度` | チェック判定の信頼度 |
| 11 | `違反数` | 検出された違反件数 |
| 12 | `違反箇所` | 違反セル範囲。複数の場合はセミコロン区切り |
| 13 | `違反内容` | 違反説明。複数の場合はセミコロン区切り |
| 14 | `違反重大度` | セル単位の重大度。複数の場合はセミコロン区切り |
| 15 | `メッセージ` | 補足メッセージ |

### CSV 出力例

```csv
ファイル名,シート名,テーブル範囲,ヘッダー範囲,列数,ルールID,合否,判定対象外,重大度,信頼度,違反数,違反箇所,違反内容,違反重大度,メッセージ
data.xlsx,Sheet1,A1:E10,A1:E1,5,L1-01,合格,,fatal,1.00,0,,,,
data.xlsx,Sheet1,A1:E10,A1:E1,5,L1-12,不合格,,critical,0.95,1,Sheet1!A1:D1,結合セルが検出されました,error,1件のセル結合が検出されました
```

違反件数が多い場合、CSVでは代表セル範囲とグループ集計を使って要約されます。JSONの `違反` には全件の違反データが保持されます。

CSV ファイルはエンコーディング `UTF-8 BOM付き`（`utf-8-sig`）で出力されます。Excel で直接開いた場合に文字化けしません。

## 複数ファイル一括分析の出力

複数ファイルを一括分析（`analyze_bulk`）した場合、単一ファイルとは異なる出力構造になります。

### JSON（Bulk）

```json
{
  "複数ファイル総合スコア": 85,
  "ファイル数": 2,
  "ファイル横断チェック": {
    "L3-07": {
      "ルールID": "L3-07",
      "合否": true,
      "判定対象外": false,
      "重大度": "critical",
      "信頼度": 0.80,
      "違反": [],
      "メッセージ": "フォーマットの一貫性に問題はありません"
    }
  },
  "ファイル別平均スコア": [
    {"ファイル名": "2023.xlsx", "平均スコア": 90},
    {"ファイル名": "2024.xlsx", "平均スコア": 80}
  ],
  "ファイル別結果": [
    { ... },
    { ... }
  ]
}
```

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `複数ファイル総合スコア` | integer | 全ファイルの平均スコア（0〜100）とbulkチェック合格率の加重平均（7:3） |
| `ファイル数` | integer | 評価対象ファイル数 |
| `ファイル横断チェック` | object | ルールID をキーとするファイル横断チェック結果。構造は単一ファイルの `評価内容` 要素と同じ |
| `ファイル別平均スコア` | array | ファイルごとの平均スコア（L1/L2/L3 の未チェック除き平均） |
| `ファイル別結果` | array | 単一ファイルJSONと同じ構造のオブジェクトの配列 |

### CSV（Bulk）

単一ファイル CSV と同じ15列構成です。全ファイルの行を出力した後、`ファイル名="(bulk)"` として各ファイル横断チェックの結果を末尾に追記します。

```csv
ファイル名,シート名,テーブル範囲,...,ルールID,合否,...
2023.xlsx,Sheet1,A1:E10,...,L1-01,合格,...
2024.xlsx,Sheet1,A1:E10,...,L1-01,合格,...
(bulk),,,,...,L3-07,合格,...
```

## 信頼度（confidence）の解釈

信頼度は各チェック結果に付与される 0.0〜1.0 の値です。

| 信頼度 | 意味 |
-------|------|
| `1.0` | 決定論的に明確に判定できた |
| `0.7` 以上 | 概ね確信度が高い |
| `0.5` 以上 `0.7` 未満 | 目視確認を推奨 |
| `0.0` 超 `0.5` 未満 | 低確信 |
| `0.0` | 未実行、エラー、または判定対象外 |
